This repository contains an interactive R-based GUI for statistical modelling and data visualization. It allows users to import data, run models, and generate plots through an easy-to-use interface without writing R code. 

The application is built using R and Shiny, with supporting scripts for data processing, model execution, and plotting. On Windows, the app can be launched directly using the included `run.bat` file. 

Alternatively, it can be run from R by loading the Shiny library and calling `runApp()` on the project folder. 
This tool is intended for researchers and analysts who want a streamlined way to explore and visualize model results interactively.
